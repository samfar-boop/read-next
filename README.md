# Read Next

An interactive web of nearly 10,000 books linked by the readers who loved them, plus a finder for parents: set a reader's age, add books they loved, and get books that fit all of them.

Live site: https://samfar-boop.github.io/read-next/

Data: [goodbooks-10k](https://github.com/zygmuntz/goodbooks-10k), about 6 million Goodreads ratings collected around 2017. Age bands are estimates from reader tags, not content ratings.
